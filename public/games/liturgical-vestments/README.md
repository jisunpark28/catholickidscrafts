# Liturgical vestments game — custom art

All layers share one coordinate system so they stack cleanly:

| Layer | Filename (optional PNG) | Size (px) |
|-------|-------------------------|-----------|
| Base (black cassock only) | `priest-cassock.png` | **240 × 480** |
| Alb | `alb.png` | **240 × 480** |
| Chasuble | `chasuble-green.png`, `chasuble-purple.png`, `chasuble-white.png`, `chasuble-red.png`, `chasuble-rose.png` | **240 × 480** |

- Use **PNG with transparency**.
- Keep the figure centered; feet near the bottom of the canvas.
- The game ships with inline SVG art; add PNGs here only if you want to replace the built-in drawings.
