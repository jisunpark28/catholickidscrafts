# Lesson UI icons

Unicode emoji are **not** used in lesson UI. All icons are inline SVG via `LessonIcon` / `LessonBlockIcon`.

## Spec

- viewBox `0 0 24 24`
- stroke `1.5`, `currentColor`, round caps
- default color: `--color-muted`
- active step title: `--color-ink`
- sizes: sm 18px, md 20px, lg 28px (add grid only)

## Block mapping

| Type | Icon |
|------|------|
| CUSTOM_NOTE | clipboard |
| PLAY_GAME | puzzle |
| TYPING_WORDS | keyboard |
| HANGMAN_WORDS | hangman figure |
| GOSPEL_TYPING | cross (simple stroke) |
| BIBLE_CHAPTER | book-open |
| RESOURCE | scissors |
| MASS_TODAY | calendar |

Share sheet: `building` (classroom), `home` (at home).

Reference tone: [Il était une fois…](https://iletait1fois.ca/) — small monochrome icons beside text, not colorful emoji.
